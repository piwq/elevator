# Elevator — симуляция пассажирского лифта жилого дома

Научно обоснованная симуляция движения пассажирского лифта в жилом многоэтажном доме:
кинематика кабины с ограничением рывка (jerk), стохастическая генерация пассажиропотока
по суточному профилю жилого здания, алгоритм диспетчеризации, метрики качества
обслуживания по CIBSE Guide D / ISO 8100-32.

## Документация

- [`docs/RESEARCH.md`](docs/RESEARCH.md) — обзор мировых подходов: классическая теория
  лифтового трафика (Barney & Al-Sharif), модели пассажиропотока, алгоритмы
  диспетчеризации, существующие симуляторы (Elevate, KONE BTS, LiftSim), метрики
  и методология валидации. С источниками.
- [`docs/DESIGN.md`](docs/DESIGN.md) — проект симулятора: архитектура,
  параметры по умолчанию с обоснованием, план валидации.
