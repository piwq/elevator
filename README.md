# Elevator — симуляция пассажирского лифта жилого дома

Научно обоснованная симуляция движения пассажирского лифта в жилом многоэтажном доме:
кинематика кабины с ограничением рывка (jerk), стохастическая генерация пассажиропотока
по суточному профилю жилого здания, алгоритм диспетчеризации, метрики качества
обслуживания по CIBSE Guide D / ISO 8100-32.

## Документация

- [`docs/RESEARCH.md`](docs/RESEARCH.md) — обзор мировых подходов: классическая теория
  лифтового трафика (Barney & Al-Sharif), модели пассажиропотока, алгоритмы
  диспетчеризации, существующие симуляторы (Elevate, KONE BTS, LiftSim), метрики
  и методология валидации. С источниками.
- [`docs/DESIGN.md`](docs/DESIGN.md) — проект симулятора: архитектура,
  параметры по умолчанию с обоснованием, план валидации.

## Запуск

Зависимостей нет (Python ≥ 3.10, стандартная библиотека; pytest — только для тестов).

```bash
# живая симуляция в браузере (анимация шахты, очереди, метрики, управление скоростью)
python3 -m web.server                                  # http://localhost:8000
python3 -m web.server --scenario tower-25.json         # другой сценарий

# научный прогон по методологии ISO 8100-32: реплики, warm-up, 95% ДИ
python3 run_experiment.py --percent 6 --reps 10
python3 run_experiment.py --scenario scenarios/panel-9.json

# верификационные тесты (кинематика, K-S тест генератора, RTT против формулы Barney)
python3 -m pytest tests/
```

## Сценарии

Все параметры симуляции задаются JSON-файлами в `scenarios/` (переключаются
на лету из веб-интерфейса): этажность и высоты этажей, население (из квартир
или явным массивом по этажам), скорость/ускорение/рывок кабины, вместимость,
времена дверей и пересадки, парковка, пиковый спрос (% населения за 5 мин),
средний размер группы, суточный профиль (часовые срезы: интенсивность и микс
входящих/исходящих/межэтажных потоков). Схема описана в `sim/scenario.py`;
неизвестные ключи отклоняются (защита от опечаток). В комплекте: базовая
17-этажка, панельная 9-этажка, 25-этажная башня.

## Структура

```
sim/        ядро: кинематика S-кривой, событийный движок, кабина,
            full selective collective, Пуассоновский генератор групп,
            суточный профиль жилого дома, метрики, методология прогонов
tests/      верификация по плану DESIGN.md §4
web/        realtime-визуализация: SSE-сервер (stdlib) + одностраничный фронтенд
docs/       исследование и проектные решения
```

## Возможности

- **Группа до 8 лифтов**: одиночный — full selective collective, группа —
  Nearest Car (figure of suitability, Barney) с перераспределением вызовов.
- **Терпение пассажиров**: не дождавшиеся уходят пешком (`demand.patience_s`).
- **Энергомодель**: упрощённый привод с противовесом + дежурное потребление.
- **Вывод кабины в ремонт** на лету из веб-интерфейса: довозит своих, новых не берёт.
- **Веб**: анимированные человечки в очередях, несколько шахт, телеметрия
  x/v/a, перемотка истории прогона ползунком (replay), диаграмма траекторий
  кабин, тепловая карта ожиданий «этаж × час», гистограмма, таблица
  пассажиров, отчёт с вердиктами ISO/CIBSE, выгрузка CSV.

## Статус

- Этап 1 — исследование предметной области: **завершён**.
- Этап 2 — ядро симуляции: **готово и верифицировано** — насыщенный up-peak
  воспроизводит аналитический RTT Barney & Dos Santos с отклонением −0,6%;
  36 верификационных тестов.
- Этап 3 — realtime веб-визуализация: **готова** (мульти-лифт, replay, отчёты).
- Дальше: ETA-диспетчер и A/B-сравнение алгоритмов, RL-песочница.
